Facility / Project Sub-Type

This field replaces the old Pharma-only “Facility Type”. The options below change automatically based on the selected industry.

No project should get blocked: every group includes Other / Custom Facility. Also allow Primary + Secondary selection because a client may have a combined facility such as Solar + BESS, Hospital + Medical College, or API + Formulation + Warehouse.

Service Type – Common for Every Facility

Design Only

Engineering calculations, reports, drawings, equipment schedules, GFC/IFC and approvals.

BIM Only

Modeling, LOD, coordination, clash detection, shop drawings, COBie and as-built.

Design + BIM

Design and BIM together in one connected workflow.

Final Logic

Industry Group → Facility Type → Optional Combined Facility → Design / BIM / Both → Discipline → Stage → Standards → Tasks → Deliverables
Developer rule: do not hard-code the workflow only by industry name. Workflow must be generated from the combination of Industry + Facility Type + Service Type + Discipline + Stage + Country.
