Qualigrafo – Final Project Classification Structure

Current recommended scope: 4 project groups with common Design / BIM / Design + BIM service logic.

1. Final Main Project Groups

Group 1 – Energy & High-Tech

  • Solar Industry / Solar PV
  • Renewable Energy
  • Semiconductor Industry

Sub-types can be selected after the main group.

Group 2 – Hospital / Healthcare

  • Hospital
  • Multi-Speciality Hospital
  • Medical College / Healthcare Facility
  • Diagnostic / Clinical Facility

Group 3 – Pharma Industry

  • API
  • Non-Sterile
  • Sterile
  • Biologics
  • Cleanroom
  • Beta-Lactam
  • Pharma Warehouse / R&D

Group 4 – Common Building Projects

  • Residential
  • Commercial
  • School / Education
  • Hotel / Hospitality
  • Warehouse / Logistics
  • Industrial / Manufacturing
  • Mixed Use
  • Other / Custom

2. Common Service Selection for Every Project

This selection must come immediately after the project group/type because sometimes the enquiry is only Design, sometimes only BIM, and sometimes both together.

Project Type → Service Type → Disciplines → Stage → BIM Level (if applicable) → Deliverables
Service TypeWhen SelectedSystem Should Load
Design Only Client requires engineering/design services without BIM modelling as the main scope. Design basis, calculations, reports, drawings, schedules, authority requirements, QA/QC, approvals and GFC/IFC deliverables.
BIM Only Design inputs are already provided and scope is BIM modelling / coordination / documentation. BEP, model setup, LOD, modelling, clash detection, coordination, shop drawings, model QA/QC, COBie/as-built as applicable.
Design + BIM Morph/consultant is responsible for both engineering design and BIM execution. Complete design workflow + BIM workflow together, linked through common approvals, RFIs, deliverables and revision control.

3. Recommended Project Creation Flow

  1. Project Information – Project Name, Client, Location, Country, Project Code
  2. Main Project Group – Energy & High-Tech / Hospital / Pharma / Common
  3. Project Sub-Type – e.g. Solar PV, Semiconductor Fab, Hospital, API Plant, Residential Tower
  4. Service Type – Design Only / BIM Only / Design + BIM
  5. Discipline Selection
  6. Project Stage
  7. BIM Requirement – only shown when BIM or Design + BIM is selected
  8. Applicable Standards – system suggested based on type/country
  9. Generate Project Workspace

4. Discipline Logic

Common disciplines:

Architecture Structure HVAC Electrical Plumbing Fire Fighting ELV / ICT Civil Interior Landscape

Industry-specific disciplines should appear automatically:

  • Solar / Renewable: Solar PV, Power Systems, SCADA, BESS, Electrical Infrastructure
  • Semiconductor: Cleanroom, Process Utilities, Specialty Gas, High-Purity Piping, Exhaust, Tool Hook-up
  • Hospital: Medical Gas, Healthcare HVAC, OT/ICU systems, Nurse Call / ELV
  • Pharma: Cleanroom, Process, Piping, Equipment, HVAC Qualification, Validation

5. Service-Specific Screen Behaviour

If user selects Design Only

Show design criteria, calculations, equipment selection, drawings, reports, schedules, authority submissions, design review, QA/QC and GFC/IFC workflow. Hide unnecessary BIM-specific fields.

If user selects BIM Only

Show input drawings/models, Revit version, CDE, BEP, LOD, model breakdown, clash matrix, coordination, shop drawings, asset information, COBie and as-built requirements. Hide design-calculation workflow unless specifically selected.

If user selects Design + BIM

Show both workflows together and connect design revisions directly with BIM model revisions, coordination issues, RFIs, approvals and final handover.

7. Final Core Logic

PROJECT GROUP → PROJECT SUB-TYPE → DESIGN / BIM / DESIGN+BIM → DISCIPLINE → STAGE → BIM LEVEL → STANDARDS → TASKS → DOCUMENTS → APPROVALS → DELIVERABLES

This should be the core project-generation logic in Qualigrafo. The same platform can then support different industries without forcing pharma-specific fields into hospital, solar, semiconductor or ordinary building projects.
