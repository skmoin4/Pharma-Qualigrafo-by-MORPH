Start-to-Handover Project Management Architecture

One platform for Pharma, Hospital, Solar/Renewable, Semiconductor and Common Design/BIM projects — with controlled tasks, documents, revisions, approvals and final handover.

Project → Scope → Tasks → Documents → Review → Revision → Approval → Construction → Commissioning → Handover

What Was Missing & Must Be Added

Must Add

Revision Control

Clear difference between file version and formal revision, with status, reason, reviewer and superseded record.

Must Add

Transmittals

Controlled issue of drawings/documents to client, contractor, consultant and authority.

Must Add

Change Control

Every scope/design change must show impact on cost, time, models, drawings and approvals.

Must Add

Commissioning & Handover

Structured test records, punch closure, as-builts, O&M, assets, warranties and final dossier.

Use one unified workflow engine. Do not build separate unrelated systems for Pharma, BIM, Hospital or Renewable projects. Industry should load templates; the underlying control engine should remain common.

Revision Control – Must Be Very Strong

Each Formal Revision Must Store

  • Revision ID
  • Previous Revision
  • Revision Date
  • Revision Description / Change Summary
  • Reason for Issue
  • Status / Suitability
  • Prepared / Checked / Approved by
  • Linked RFI / Change / NCR / Task
  • File checksum / integrity reference where required
  • Issued through Transmittal

User Functions

  • Compare two revisions
  • See markups / comments
  • See full revision tree
  • Identify current approved revision
  • Prevent accidental use of superseded files
  • Download issue history
  • Restore prior working version with permission
  • Generate revision register automatically
Rule: Never overwrite the previous formal revision. A new revision is a new controlled record linked to the old revision.

Final Developer Architecture

One Data Model:
Industry + Facility + Service + Discipline + Stage + Country determine which templates are loaded.

Common Control Engine:
Tasks + Documents + Versions + Revisions + Reviews + Approvals + Transmittals + RFIs + Changes + Audit Trail are common across all industries.

Industry Add-ons:
Pharma validation, hospital medical systems, solar/renewable energy packages and semiconductor process utilities are modular additions—not separate applications.

Standards / Design References for the Product Team

  • ISO 19650 information-management principles: recording, versioning, organizing and lifecycle information management.
  • CDE guidance: information container ID, status, revision, classification, transition records and controlled access.
  • Pharma computerised systems: lifecycle controls around validation, data, identity/access, audit trails, electronic signatures, security, backup and archiving.
  • Cleanroom projects: cleanroom classification and equipment suitability requirements should be configurable by project and jurisdiction.
Do not hard-code standards as universally applicable. Qualigrafo should suggest them based on country, industry, facility and scope, then allow the project administrator to confirm or edit applicability.
