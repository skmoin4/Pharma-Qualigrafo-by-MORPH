2. Actual Problems Found

Priority Issue Actual Behaviour Expected Behaviour
P0 – Critical Wizard cannot progress After completing Step 1 and Step 2, clicking Next sends the user back to an earlier step instead of progressing. Valid data should move the user sequentially from Step 1 → 2 → 3 → 4 → 5.
P0 – Critical Plant Country value resets The selected Plant Country does not reliably remain saved. It can revert to the default country when moving between steps. The selected country must persist for the entire wizard and project lifecycle.
P0 – Critical Step 2 state is not persistent Facility type, market and scope information appears to lose state when navigation changes. All selections must remain intact until project creation is completed or the user manually changes them.
P1 – High Regulatory market logic depends on unstable country state Plant Country controls the local regulatory authority, but because the country can reset, the regulatory scope becomes unreliable. Country and regulatory authority should remain synchronized and validated.
P1 – High Steps 3–5 cannot be tested Registers, Team and Review/Create could not be reached due to the wizard issue. All steps must be accessible after previous required fields are completed.
P1 – High Project is not actually created The entered project data does not reach the final Create action. The Review step should display a summary and create the project successfully.

3. Current Wizard Structure

  1. Basics – Project name, client, location, plant country
  2. Scope & Markets – Facility type, project scope, phase, target markets
  3. Registers – Regulatory/document registers
  4. Team – Project team and roles
  5. Review – Final review and project creation

4. Existing Pharma Logic Observed

The current system is strongly pharma-oriented and already contains useful pharma-specific configuration.

  • Facility Types: API, Non-sterile Formulation, Sterile Products, Biologics, Warehouse
  • Project Scope: New Plant, Expansion, Renovation, Equipment Installation
  • Markets / Authorities: SFDA, CDSCO, EMA, FDA, MHRA
  • Platform Modules visible: Portfolio, My Work, Regulatory Watch, Requirement Library, Users & Access

5. Developer Fix Order

  1. Fix wizard state management first. Form values must be stored centrally and not reset on step change.
  2. Fix Plant Country persistence. The selected country must not revert to the default value.
  3. Fix Next button routing. The button should validate the current step and navigate only to the next step.
  4. Synchronize Plant Country and Target Market. If India is selected, India/CDSCO should be auto-included and retained.
  5. Add clear validation messages. If a required field is missing, show the exact field instead of silently returning to another step.
  6. Preserve Step 2 selections. Facility Type, Scope, Phase and Markets must survive Back/Next navigation.
  7. Verify final Create flow. Review page should summarize all data before final creation.

6. Recommended Technical Check

Check wizard form-state handling: - React/local state vs global projectDraft state - Route/step re-render resetting defaults - select input defaultValue vs controlled value - onChange not writing to persistent state - Step navigation re-initializing project model - validation handler redirecting incorrectly - plantCountry → targetMarkets dependency overwriting user state
